# Ackermann NN–Fuzzy–PID Reproducibility Package

This repository provides reproducibility code and numerical datasets for the manuscript:

**A Structured Neural-Supervised Fuzzy–PID Steering Controller with ISS Guarantees for Nonlinear Ackermann Vehicles**

## Repository description

Reproducibility code and datasets for NN–Fuzzy–PID steering control of nonlinear Ackermann autonomous vehicles.

## What is publicly released

This repository publicly releases:

1. Python source code for reproducing the control-oriented simulations.
2. Baseline PID, Fuzzy–PID, proposed NN–Fuzzy–PID, and MPC benchmark implementations.
3. Simulation scenarios and disturbance profiles.
4. Vehicle, controller, simulation, and benchmark configuration files.
5. Time-series CSV datasets generated by the Python reproducibility code.
6. Performance tables used for independent verification.

## Reproducibility and data-origin statement

Only data, source code, and results that are consistent with their actual origin and can be independently rerun or verified are made publicly available. The Python-based reproducibility data are not presented as original MATLAB/Simulink or Simscape Multibody outputs unless they were directly exported from those models. The publicly available files are provided to support verification of the controller algorithm, simulation configuration, parameter settings, performance metrics, and post-processing workflow.

Full MATLAB/Simulink or Simscape Multibody implementation files are not included in this public repository unless explicitly stated. Such files may depend on commercial software licences, toolbox-specific components, or institutionally developed models, and may be provided by the corresponding author upon reasonable request for academic verification purposes, subject to legal, technical, software-licence, and institutional constraints.

## Installation

```bash
pip install -r requirements.txt
```

## Run all simulations

```bash
python scripts/run_all.py
```

Running the script will regenerate CSV datasets, figures, and performance tables.

## Output folders

```text

results/figures/        generated figures after rerunning scripts
results/tables/         performance tables
config/                 vehicle, controller, scenario, and disturbance settings
```
